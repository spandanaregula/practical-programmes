# Web Development Practical Lab

This workspace contains practice exercises for HTML, CSS, and JavaScript/Java programming.

## Folder Structure

- `html/` - HTML examples covering headings, lists, tables, forms, media, semantic elements, input types, timetables, Bootstrap, and a portfolio.
- `css/` - CSS examples covering selectors, colors, typography, box model, positioning, Flexbox, Grid, responsive design, animations, effects, and complete layouts.
- `javascript/` - 67 programming exercises. These files currently contain Java source code but use the `.js` extension because of the requested folder naming.
- `index.html/` - Project landing page at `index.html/index.html`.

## How To Use

1. Open `index.html/index.html` in a web browser.
2. Choose an HTML or CSS exercise from the links on the page.
3. Open the JavaScript folder files in an editor to study the source.
4. To compile the Java programs, rename a file from `.js` to `.java`, then run:

```bash
javac Ex01_HelloWorld.java
java Ex01_HelloWorld
```

## Notes

The HTML and CSS examples are standalone pages and mostly use inline styles or public demonstration assets. Some media, image, Bootstrap, and API examples require an internet connection.
