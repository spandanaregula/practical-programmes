# JavaScript and Node.js Lab

The original numbered JavaScript exercises remain in this folder. New practical work is grouped into subfolders:

- `dom-manipulation/` - dynamic elements, styles, selectors, tables, filters, counters, password visibility, dropdowns, dependent dropdowns, and slideshow.
- `events/` - mouse, keyboard, form, double-click, bubbling/capturing, delegation, keyboard movement, and drag-and-drop.
- `forms-validation/` - registration, login, password strength, signup confirmation, feedback, admission, and dynamic errors.
- `browser-storage/` - Window, Navigator, Location, History, localStorage, sessionStorage, cart, and theme persistence.
- `mini-projects/` - calculator, clock, stopwatch, countdown, todo, APIs, quiz, guessing game, tic-tac-toe, expenses, grades, cart, notes, password, BMI, currency, and portfolio interactions.
- `node-js/` - Node HTTP, Express, routing, middleware, cookies, sessions, CRUD, database-style persistence, authentication, authorization middleware, and REST APIs.

Open each `index.html` in a browser for frontend experiments. For Node examples, open `node-js/README.md`, run `npm install`, and then run the desired `.js` file with Node.js.
