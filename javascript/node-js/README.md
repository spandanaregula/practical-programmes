# Node.js Backend Lab

Run `npm install` in this folder before Express, cookie, session, or authentication examples.

- `01-client-server.js`, `02-http-server.js`: client-server architecture, HTTP request/response, HTML and JSON responses.
- `03-built-in-modules.js`, `04-filesystem.js`, `12-custom-module.js`, `math-module.js`, `13-async-patterns.js`: Node fundamentals, `path`, `os`, `url`, `fs`, custom modules, callbacks, promises, async/await, and error handling.
- `05-express-server.js`: Express app, GET/POST, static files, modular JSON handling, and 404 response.
- `06-routing-middleware.js`: route parameters, query parameters, routers, logging, validation point, and error middleware.
- `07-cookies-sessions.js`: cookies, sessions, login, logout, and protected profile route.
- `08-crud-memory.js`, `11-database-json.js`: CRUD and persistent JSON database-style operations.
- `09-authentication.js`: registration, bcrypt password hashing, verification, JWT login, and protected API route.
- `10-rest-api.js`: GET, POST, PATCH, DELETE, status codes, validation point, and API 404 handling.

Start examples with `node filename.js`. Start Express with `npm run express`; start the REST API with `npm run api`.
